`editor.html` es la versión maestra. Necesita estar junto a una carpeta `assets/models/` para cargar los SVG (por eso cada proyecto trae su copia en `proyectos/<x>/editor.html`).
Para trabajar: copiar este archivo a la carpeta del proyecto y abrirlo desde un servidor (por ejemplo `python3 -m http.server` dentro de esa carpeta).
